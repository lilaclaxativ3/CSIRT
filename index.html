🚨 CSIRT Incident Response Framework

INCIDENT RESPONSE FRAMEWORK

Computer Security Incident Response Team (CSIRT)
Designing and deploying the best threat models still doesn't ensure full protection of data from cyber incidents. Incident Response (IR) is the critical next step — a structured methodology for detecting, containing, eradicating, and recovering from security incidents while preserving organizational reputation and business continuity. The CSIRT operationalizes this through six core phases.
1 — WHY INCIDENT RESPONSE MATTERS Context: From threat modeling to active defense — bridging the gap when prevention fails

🎯 The Reality of Cyber Incidents

No security architecture is impenetrable. Despite robust threat models (STRIDE, PASTA, LINDDUN), defense-in-depth strategies, and zero-trust architectures, adversaries continue to find gaps.

Incident Response is the disciplined process a CSIRT follows when a security event becomes a confirmed incident. It transforms chaos into coordinated action — minimizing damage, reducing recovery time, preserving forensic evidence, and feeding lessons back into the security posture.

The NIST SP 800-61 framework defines six interconnected phases that form a continuous lifecycle — not a one-time checklist.

3 — DETAILED PHASE BREAKDOWN Key activities, tools, and deliverables for each CSIRT phase
01

PREPARATION

Foundation of all IR capability

▸ Key Activities

  • Develop & approve IR policy and plan
  • Build CSIRT — define roles, RACI matrix
  • Deploy IR tooling (SIEM, SOAR, EDR, forensic kits)
  • Establish communication trees & war room
  • Conduct tabletop exercises quarterly
  • Integrate threat intelligence feeds
  • Create incident classification taxonomy

⚙ Tools & Resources

  • SIEM (Splunk, Sentinel, QRadar)
  • SOAR (Phantom, XSOAR, Swimlane)
  • Ticketing (ServiceNow, Jira)
  • Threat Intel (MISP, OTX, VirusTotal)

✦ Deliverables

  • IR Policy & Plan document
  • Playbook library (per incident type)
  • Contact / escalation matrix
  • Asset inventory & baseline configs
02

IDENTIFICATION

Detection & triage of security events

▸ Key Activities

  • Monitor SIEM dashboards & alerts 24/7
  • Triage: true positive vs false positive
  • Correlate events across data sources
  • Classify severity (P1–P4)
  • Assign incident handler & open ticket
  • Begin initial scoping & impact assessment
  • Formally declare incident if confirmed

⚙ Tools & Resources

  • SIEM correlation rules & alerts
  • EDR (CrowdStrike, SentinelOne, Carbon Black)
  • UEBA / NTA (Darktrace, Exabeam)
  • Threat hunting frameworks (MITRE ATT&CK)

✦ Deliverables

  • Incident ticket with initial classification
  • Preliminary scope & affected assets
  • Severity rating & escalation trigger
  • Initial IOC collection
03

CONTAINMENT

Limiting damage & preserving evidence

▸ Key Activities

  • Short-term: isolate hosts, block IPs/domains
  • Long-term: deploy temp patches, re-segment
  • Disable compromised accounts & API keys
  • Create forensic disk/memory images
  • Preserve logs & evidence (chain of custody)
  • Activate backup communication channels
  • Notify legal, compliance, executive team

⚙ Tools & Resources

  • Network ACLs, firewall rules, NAC
  • EDR isolation (host quarantine)
  • FTK Imager, dd, KAPE (forensic imaging)
  • Volatility (memory forensics)

✦ Deliverables

  • Containment actions log (timestamped)
  • Forensic images with hash verification
  • Updated scope & blast radius
  • Stakeholder notification records
04

ERADICATION

Eliminating the threat completely

▸ Key Activities

  • Remove malware, rootkits, backdoors
  • Perform root cause analysis (RCA)
  • Patch exploited vulnerabilities
  • Reset all compromised credentials
  • Sweep entire environment for IOCs
  • Harden configurations & close gaps
  • Verify no persistence mechanisms remain

⚙ Tools & Resources

  • AV / EDR full scans + YARA rules
  • Vulnerability scanners (Nessus, Qualys)
  • IOC scanners (Loki, Thor)
  • Configuration audit tools (CIS Benchmarks)

✦ Deliverables

  • Root cause analysis report
  • Complete IOC list (hashes, IPs, domains)
  • Patch / remediation verification log
  • Clean bill of health scan results
05

RECOVERY

Restoring operations safely

▸ Key Activities

  • Restore systems from verified clean backups
  • Rebuild compromised systems from gold images
  • Phased reconnection (staged rollout)
  • Enhanced monitoring for re-infection (30–90 days)
  • Validate system integrity (pen test / vuln scan)
  • Resume business operations gradually
  • Issue customer / regulatory notifications

⚙ Tools & Resources

  • Backup / DR platforms (Veeam, Commvault)
  • Golden image repositories
  • Enhanced SIEM alerting rules
  • Penetration testing frameworks

✦ Deliverables

  • System restoration verification report
  • Enhanced monitoring dashboard
  • Business resumption confirmation
  • Regulatory notification records
06

LESSONS LEARNED

Post-incident improvement cycle

▸ Key Activities

  • Conduct Post-Incident Review (PIR) meeting
  • Reconstruct complete incident timeline
  • Identify what worked / what failed
  • Gap analysis + what-if scenarios
  • Update IR plans, playbooks, runbooks
  • Revise policies & security controls
  • Update threat models (feed back to STRIDE)

⚙ Tools & Resources

  • PIR meeting template & facilitator
  • Timeline visualization (Timesketch)
  • Knowledge base / wiki updates
  • Training platform (range exercises)

✦ Deliverables

  • Post-Incident Report (executive + technical)
  • Updated IR playbooks & procedures
  • Improvement action items (tracked)
  • Updated risk register & threat model
4 — INCIDENT SEVERITY & ESCALATION MATRIX Classification framework used during Phase 2 (Identification) to determine response urgency and team activation
Severity Classification Examples Response Time Escalation CSIRT Activation
SEV-1 CRITICAL Business-threatening Active ransomware, data breach of PII/PHI, nation-state APT, complete system compromise Immediate (≤15 min) CISO → CEO → Board. Legal, PR activated. Law enforcement notification Full CSIRT + Executive War Room + External IR Retainer
SEV-2 HIGH Significant impact Privileged account compromise, lateral movement detected, DDoS affecting services ≤ 30 minutes CISO → IT Director. Legal on standby Core CSIRT activated + specialized SMEs
SEV-3 MEDIUM Moderate impact Malware on single host, phishing with credential harvesting, unauthorized access attempt ≤ 4 hours SOC Manager → IR Lead SOC team + IR analyst on-call
SEV-4 LOW Minimal impact Policy violation, failed brute-force, spam campaign, minor misconfiguration Next business day SOC L1/L2 handles. Documented in ticket SOC standard operations
